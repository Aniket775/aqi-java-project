CPCB Calculation Architecture

1. ACID Transaction: Measurement is persisted, sub-index evaluated, and daily station history updated within a Java @Transactional boundary.

2. Continuous Breakpoints: Linear interpolation formula eliminates decimal boundary gaps:

I = ((I_hi - I_lo) / (C_hi - C_lo)) * (C - C_lo) + I_lo

3. CPCB Sufficiency Rule: Overall AQI requires at least 3 pollutants, and at least one must be PM2.5 or PM10.

4. De-duplicated Alerting: Data-quality alerts are managed by the MySQL trigger; overall AQI threshold alerts are managed by Java AlertService.
