MySQL Stored Procedure with Cursor Execution

Executing this report triggers the MySQL procedure sp_generate_city_report(p_city_id, p_user_id). The procedure initializes a MySQL CURSOR to iterate through each active station in the municipal jurisdiction, populates an aggregated temporary table with 30-day pollutant statistics (avg & max PM2.5/PM10), writes the audit trail to report_log, and returns the aggregated dataset.
