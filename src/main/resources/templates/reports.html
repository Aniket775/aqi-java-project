MySQL Stored Procedure with Cursor Demonstration

Selecting a city executes the MySQL stored procedure sp_generate_city_report(p_city_id, p_user_id). The procedure initializes a MySQL CURSOR to iterate through each active station in the city, creates a TEMPORARY TABLE, aggregates 30-day pollutant statistics (avg & max PM2.5/PM10), records the audit trail in report_log, and returns the aggregated result set.
